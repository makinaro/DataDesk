## Round 1 report (summary)

- **[Critical] The trust boundary between agent code and main was unspecified.** Python owns the worker realm through the `js` FFI, so any cap applied in the window is advisory, and a forged result frame can bypass stdout limits.
- **[Major] Architecture:** partition model undefined (one shared partition lets lanes talk through `BroadcastChannel` and IndexedDB, and `onBeforeRequest` listeners overwrite each other); output spill made the host a second file writer.
- **[Major] Decisions:** Q9's 2 GB soft limit vs D-031's 500 MB growth; the compute CSP needs a rule-2 waiver D-NNN; the tuning gate looser than D-035.
- **[Major] Buildability:** Electron facts (per-partition protocol, cross-origin isolation on a custom scheme, workers, `getAppMetrics`, `NODE_OPTIONS`) not routed to docs-researcher; the CPython fallback can't be built inside P13.
- **[Major] Operability:** hidden windows break `window-all-closed`, `second-instance` focus and the agent-event broadcast; host failures unmapped to statuses.
- **[Major] Measurability:** no positive control (network canaries), no denial log for M-11, no result file; perf workloads unpinned, `windows-latest` moving.
- **[Major] Safety:** row exfiltration through the in-worker harness; provenance forgery by monkeypatching that survives replay; blocked code exported to the user's Jupyter; permissions granted by default on non-default sessions; cross-lease channels.
- **[Major] Statistics:** Pyodide and `bench/env` library versions differ.
- **[Major] Completeness:** Entry and inputs vs the roadmap; no phase builds the evaluation kernel.
- **Q-level:** Q1 path handling and privileges; Q2 "unresponsive" undefined, native loops; Q3 denial ≠ nothing left; Q5 units and estimators; Q6 export hazards (belongs to P21); Q7 unverified `NODE_OPTIONS` claim, `dgram`; Q8 lazy hashing and TOCTOU, overclaimed tamper detection; Q9 `workingSetSize`; Q10 false DuckDB comparison, trust on first use, dependency closure.
- **Minor/Nit:** stale window counts, CSP location, gate location, P23 duplicate, missing "Done when", undefined terms, size, cold start, EC13-3 import-only, installer vs installed size, question order.

## Questions for the maintainer (defaults applied)

- **Q-H1. Channel to main.** Default: a minimal preload with two functions; every limit is enforced in main, never in the sandbox. **Agreed (2026-10-04).**
- **Q-H2. Partitions.** Default: a fresh in-memory partition per kernel window. **Agreed (2026-10-04).**
- **Q-H3. CSP waiver.** Default: accept a recorded exception to CLAUDE.md rule 2 for the compute window's CSP (`'wasm-unsafe-eval'`). **Agreed (2026-10-04).**
- **Q-H4. Memory warning.** Default: follow D-031 (warn on 500 MB growth), measured on private memory. **Agreed (2026-10-04).**
- **Q-H5. Notebook export of failed cells.** Default: exported commented out with a warning, plus a danger scan (decided in P21). **Agreed (2026-10-04).**
- **Q-H6. CPython fallback.** Default: if the spike fails, P13 ends there and a separate CPython phase (4–6 sessions) follows. **Agreed (2026-10-04).**
- **Q-H7. Evaluation kernel.** Default: P13 builds and tests it. **Agreed (2026-10-04).**
- **Q-H8. Same library versions.** Default: the reference environment pins Pyodide's versions. **Agreed (2026-10-04).**
- **Q-H9. Escape log.** Default: P13 adds a denial log that feeds M-11 in every later run. **Agreed (2026-10-04).**
