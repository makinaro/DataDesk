## Round 1 report (summary)

- **[Critical] Instrumentation fed gated metrics** (Q8 check 4, PA-06, EC17-3), against roadmap §8.3 principle 7 and P11-16.
- **[Critical] `predict` leaked test rows:** a matching split id let the evaluation kernel see the split source, test rows included, and a crafted pickle could return the target.
- **[Major] Architecture:** explanations placed in the predict-only evaluation kernel; leakage check 1 had no code-owned place to run.
- **[Major] Decisions:** the superseded noise rule; the agent passing the split kind; no n < 1,000 rule (who grades nested CV); no spend.
- **[Major] Recommendations:** agent-supplied baseline; no threshold channel; no `predict_proba` requirement; Q7 unbuildable at scale; Q8 check 4 detects an impossible event, check 5 is empty, checks 2–3 undefined; imbalance check missing.
- **[Major] Operability:** one failure burns the test set; every runtime upgrade strands saved models.
- **[Major] Measurability:** EC17-3's denominator is about 1; no M-07 path; M-06 had no event list.
- **[Major] Safety:** a planted whitelist suppresses a leakage check; transductive reads of the scoring set.
- **[Major] Statistics:** iid bootstrap for grouped and temporal splits; no paired comparison with the baseline.
- **Minor/Nit:** owners, tuning limits, CV-score tagging, subgroup timing, PSI bins, PCA unspecified, verified facts, bootstrap on main's loop, model retention, queued evaluations, EC17-2 count, binned charts, card limitations, out-of-fold AUC, multi-class averaging, paths, P18 hand-off, PA-06 value, done-when lines, deliverables, §1 sources, undefined terms, principle numbering.

## Questions for the maintainer (defaults applied)

- **Q-R1. Leakage checks that count.** Default: only checks computed by main count toward gates. **Agreed (2026-10-04).**
- **Q-R2. `predict` during a split.** Default: refuses data descended from the split dataset. **Agreed (2026-10-04).**
- **Q-R3. Split kind.** Default: code decides; grouped only when the task or you declare an entity column. **Agreed (2026-10-04).**
- **Q-R4. Small data (n < 1,000).** Default: nested cross-validation run by main, not by the agent. **Agreed (2026-10-04).**
- **Q-R5. Leakage gate.** Default: the dev leakage case must be caught on both providers; the holdout case is reported at P22. **Agreed (2026-10-04).**
- **Q-R6. Silencing a leakage warning.** Default: only you can. **Agreed (2026-10-04).**
- **Q-R7. Saved models after an upgrade.** Default: marked "needs retrain", with one-click retraining. **Agreed (2026-10-04).**
- **Q-R8. Failed evaluations.** Default: a test-free pre-flight first, so a broken model doesn't use up the test set. **Agreed (2026-10-04).**
- **Q-R9. Benchmark scoring data.** Default: readable only by `predict`. **Agreed (2026-10-04).**
- **Q-R10. P17 spend.** Default: ~~≈ $24~~ **≈ $29** with judging for the D-038 floor (Q-V7). **Agreed after discussion (2026-10-04).**
