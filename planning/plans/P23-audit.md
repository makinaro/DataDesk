## Round 1 report (summary)

- **[Critical] C1:** EC23-1 couldn't be met on the release artifact: the inspect fuse breaks Playwright, the fake-provider hook is stripped from the default build, and the `NODE_OPTIONS` offline guard is disabled by the new fuse.
- **[Critical] C2:** a tag-triggered workflow from any commit could publish a trojaned installer with matching checksums.
- **[Major]:** the plan contradicted the P22 freeze (aliases, new features, "functional" undefined); no spend approval; integrity claimed as tamper detection; no escape suite or hook check on the release build; orphaned snapshots and lessons; cleanup without crash, concurrency or lock handling; diagnostics leaking keys and data; no upgrade test; hand-typed README numbers; no fresh-machine pass rule; an invalid A/B sample.
- **Minor:** partial fuse list, unverified APIs, size baseline, roadmap items P23-07/P23-08 and P23-01's runtime, P10 Q32 cascade, Q8 already decided by D-045, signing pricing, DoD itemisation, undefined terms, session count.
