## Round 1 report (summary)

- **[Critical] A gate metric (PA-05) and the family counts came from in-kernel instrumentation**, which agent code can bypass (`2*stats.t.sf(...)`, private functions, reloads) or forge, against P11-16 and P13's trust boundary.
- **[Major] Architecture:** agent-written design fields granted authority (randomised, weights, allocation) and "n per group" contradicted the plan lock; chart templates had no data path; two sources of truth for acceptable tests.
- **[Major] Decisions:** families from the agent's question tags (D-035 says the task); a gate retry (D-036); judge blocking under D-038 missing; no stated spend and no owner for the official gate.
- **[Major] Buildability:** the p-hacking check couldn't link p-values in prose to calls.
- **[Major] Measurability:** EC16-2 dropped M-19 and PA-09; PA-05 had no MVP threshold or key field; M-02 gated without M-03; EC16-1's denominator included ML and forecast questions.
- **[Major] Safety:** injected design exemptions ("randomised") and weights.
- **[Major] Statistics:** family splitting; weight semantics untyped; dev overfitting through unbounded pre-gate runs.
- **Minor/Nit:** skill context size, test identity by keyword, SRM allocation, observed power, Logit HC3, influence threshold, rubric version, calibration ablations, chart labels, unverified facts, killed executions, void vs retry, `question` field fencing, weight suggestion fencing, work-item numbering, roadmap M-09, §12.12 fields, results path, §1 citations, hand-off wording, done-when lines, deliverables, MVP summary owner, undefined terms, unmeasured heuristic.

## Questions for the maintainer (defaults applied)

- **Q-P1. How tests are scored.** Default: the agent lists the tests it relied on, and the scorer recomputes each one. **Agreed (2026-10-04).**
- **Q-P2. Test families.** Default: hypotheses locked in the plan; later questions are exploratory; the benchmark uses the task's families. **Agreed (2026-10-04).**
- **Q-P3. No gate retry.** Default: one practice run, then one official gate; a failure needs a new decision to re-run. **Agreed (2026-10-04).**
- **Q-P4. P16 spend and who runs the gate.** Default: **≈ $140** (raised from ≈ $116 in round 2 for the void contingency); a maintainer runs and pays for the official gate. **Agreed after discussion (2026-10-04).**

- **Q-P6. PA-05 at MVP.** Default: ≥ 70% (85% at v1.0). **Agreed (2026-10-04).**
- **Q-P7. What the MVP gate counts.** Default: only questions whose tools exist by P16, with M-03 ≥ 75% gated beside M-02. **Agreed (2026-10-04).**
- **Q-P8. Judge block.** Default: the gate fails if a judge block is confirmed. **Agreed (2026-10-04).**
- **Q-P9. Charts.** Default: main builds them from recorded outputs. **Agreed (2026-10-04).**
